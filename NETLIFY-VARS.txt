THE SWAP YARD — NETLIFY ENVIRONMENT VARIABLES
================================================
Netlify → your site → Site configuration → Environment variables → Add a variable

━━━ REQUIRED AT LAUNCH (9 variables) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SUPABASE_URL
  Value:  https://your-project.supabase.co
  Source: Supabase → Settings → API → Project URL

SUPABASE_ANON_KEY
  Value:  eyJ... (long string)
  Source: Supabase → Settings → API → anon public key
  Note:   Also paste into YOUR HTML FILES (index.html, vendor-dashboard.html, tax-guide.html)

SUPABASE_SERVICE_ROLE_KEY  ⚠️ SECRET — never put in HTML
  Value:  eyJ... (longer string)
  Source: Supabase → Settings → API → service_role key

RESEND_API_KEY
  Value:  re_...
  Source: resend.com → API Keys → Create API Key

FROM_EMAIL
  Value:  noreply@theswapyard.com
  Note:   Type this exactly as-is

ANTHROPIC_API_KEY  ⚠️ SECRET
  Value:  sk-ant-...
  Source: console.anthropic.com → API Keys → Create Key

ADMIN_EMAIL
  Value:  your-personal@email.com
  Note:   Receives fraud alerts and admin notifications

URL
  Value:  https://sparkly-abc123.netlify.app  (update to real domain later)
  Note:   Your Netlify site URL

AMAZON_AFFILIATE_TAG
  Value:  theswapyard-20  (your tag from Amazon Associates)
  Source: affiliate-program.amazon.com


━━━ STRIPE (card payments + vendor payouts) ━━━━━━━━━━━━━━━━━━━━━━━━━

STRIPE_PUBLISHABLE_KEY
  Value:  pk_test_...  (pk_live_... when going live)
  Source: stripe.com → Developers → API Keys
  Note:   Also paste into index.html as YOUR_STRIPE_PUBLISHABLE_KEY

STRIPE_SECRET_KEY  ⚠️ SECRET — never put in HTML
  Value:  sk_test_...  (sk_live_... when going live)
  Source: stripe.com → Developers → API Keys → Reveal

STRIPE_WEBHOOK_SECRET  ⚠️ SECRET
  Value:  whsec_...
  Source: stripe.com → Developers → Webhooks → your endpoint → Signing secret


━━━ TWILIO (SMS phone verification) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TWILIO_ACCOUNT_SID

TWILIO_AUTH_TOKEN  ⚠️ SECRET
